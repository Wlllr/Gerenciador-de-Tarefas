# 📝 Gerenciador de Tarefas (Task Manager)

Este é um projeto de gerenciamento de tarefas desenvolvido para colocar em prática conceitos de desenvolvimento web com Java e o ecossistema Spring. A aplicação permite o controle total de atividades, desde a criação até a exclusão, com uma interface amigável.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Java 25
* **Framework:** Spring Boot 3
* **Persistência:** Spring Data JPA / Hibernate
* **Template Engine:** Thymeleaf
* **Banco de Dados:** H2 (In-memory database)
* **Gerenciador de Dependências:** Maven

## ⚙️ Funcionalidades

- **CRUD Completo:** Cadastro, listagem, edição e exclusão de tarefas.
- **Atributos de Tarefa:** Gerenciamento de ID, Título, Descrição e Status.
- **Filtros:** Sistema de busca por título para localização rápida de tarefas.
- **Interface Responsiva:** Desenvolvida para ser utilizada diretamente no navegador.

## 🛠️ Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone [https://github.com/Wlllr/Gerenciador-de-Tarefas.git](https://github.com/Wlllr/Gerenciador-de-Tarefas.git)
   ```
2. Entre na pasta do projeto e execute via Maven:
   ```bash
   mvn spring-boot:run
   ```
3. Acesse no seu navegador:
  ```
   http://localhost:8080
